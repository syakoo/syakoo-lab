## カラーテーマをダークからライトに変更

さあ、一度このサイトを見ている人なら気づいたかもしれませんが、カラーテーマを変えました。

基本的に自己満を目的としているので自分が今でも利用しているダークテーマを採用していたのですが、
意外と周りはライト派もおり、読み物はライトの方が読みやすいし印象いいかなと思ったのでライトに変えました。

切り替えられるようにすれば？という話でもあるのですが、まあ別にそこまでする必要もないかなと感じています。

技術的にはカラートークンはまとめていたため一発でした。ラッキー。

## Next.js から Waku へ変更

中身の話ですが、フレームワークを Next.js から Waku へ変更しました。

https://waku.gg/

このサイトは静的生成のみであり Next.js を使う必要はないなぁと思っていたこと、Waku のアイコンが神社であることが決め手でした。（？）

Waku はまだメジャーリリースはされていないのですが、まあこのサイトは実験場でもありますので。「えいや」で。

ついでにスタイリングも vanilla-extract がうまくいかなかったので tailwindcss に移行しました。
あんまり好きではないんですが、今のメジャーではあると思うので。

## AI を Cursor から Claude Code へ変更

開発時の話ですが、個人で使ってる AI を Claude Code に変えました。
元々はエディタでもサジェストが効くし、Claude のモデル選択できるしで Cursor にしていました。

が、やはり Claude Code は正義。
キャッシュが効いているのか、使用量が体感で劇的に減りました。めちゃくちゃ使っても全然使い切れません。

それに伴い開発フローは絶賛工事中です。
安定したらまた記事にします。

## おわりに

このサイトはまだ続けていきます。まだ飽きてないので。
