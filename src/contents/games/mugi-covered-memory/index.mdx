部活で急ぐ相談者が、暗証つきの小さな箱をムギに預ける。
忘れたはずの番号に、どんな意味があったのか。

想定プレイ時間 30〜45 分の短編推理ゲームです

## はじめ方

▼ オンラインで遊ぶ場合
https://syakoo-lab.com/creations/mugi-covered-memory
こちらの URL にアクセスすると、すぐにゲームが始まります。

▼ ダウンロードして遊ぶ場合
ダウンロードしたフォルダにある「index.html」ファイルを、お使いのウェブブラウザで開くとゲームが始まります。
一度ダウンロードすれば、インターネット環境のない場所（機内モードなど）でも、ブラウザさえあればいつでも遊ぶことができます。
